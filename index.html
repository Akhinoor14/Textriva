কীভাবে ব্যবহার করবেন
1
Image বা PDF upload করুন। PDF হলে সব page আলাদা হয়ে যাবে।
2
Lens button চাপুন। Upload ছাড়াই সরাসরি Google Lens এ যাবে।
3
Lens tab এ text select করুন → Copy করুন → এই app এ ফিরে এসে paste করুন।
4
Upload-এর পর Space চাপুন। প্রথমবার প্রথম page-এর Lens খুলবে; Lens থেকে copy করে ফিরে এসে প্রতিবার Space চাপলেই paste, save, next ও পরের Lens হবে।
⌨️ Keyboard Shortcuts
Navigation
← → আগের / পরের page এ যান G Go to a page number B Toggle bookmark on this page
Text Editing
C Textarea এ selected text cut করুন
Workflow
L Current page Google Lens এ খুলুন Ctrl+Enter Text save করুন, পরের page এ যান R Clipboard paste → Save → Next (Lens ছাড়া) Space 🔥 Upload-এর পর প্রথম Lens খুলুন; এরপর paste + save + next + Lens — পুরো workflow
Preview Zoom
Z Zoom in (বার বার চাপুন বাড়াতে) X Zoom reset — original size এ ফেরা ↑ ↓ ← → Zoom অবস্থায় image pan করুন
Other
Ctrl+V Screenshot / image clipboard থেকে add করুন M / Esc এই modal বন্ধ করুন
⚡ Lens Workflow (সবচেয়ে দ্রুত)
Lens window এ → Ctrl+A → Ctrl+C → Ctrl+W
App এ ফিরে → Space চাপুন — বাকি সব automatic 🚀
